# MyPythonProject

Учебный проект: расчёт площадей и периметров геометрических фигур.

## Файлы

- `geometry.py` — функции расчёта;
- `utils.py` — ввод чисел с проверкой;
- `main.py` — точка входа.

## Запуск

```bash
git clone https://github.com/space32-web/MyPythonProject.git
cd MyPythonProject
python main.py
```

## Проверка PEP 8

```bash
pip install flake8
flake8 .
```

Результат проверки: замечаний нет.
